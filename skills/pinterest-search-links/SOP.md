# Pinterest搜索入口助手｜一页SOP

## 做什么

需求 → AI整理不同的英文搜索方向并生成链接 → 你点击进入Pinterest挑图 → 把少量候选发回来 → AI按要求判断。

适用于人物、服装、场景和画风参考。本Skill只提供链接，不自动打开网页，不读取或筛选搜索结果，也不需要浏览器扩展或本地启动脚本。

## 怎么用

> 用 $pinterest-search-links 为小户型阅读角给4个Pinterest入口，保留木质家具和自然光，方向要不同，不替我挑图。

也可以说“按pint关键词填网址的方式来”，并说明本次需求。默认给4–6个入口，具体数量以你的要求为准。若新对话没有识别到Skill，可直接提供本文件或同目录的SKILL.md。

## 双方分工

1. 你说明：找什么、必须满足什么、不要什么；已有要求不用重述。
2. AI输出：少量在画面层面真正不同的英文查询链接；中文需求先转成英文，搜索框不放中文或中英混合关键词。各组保留共同硬要求，并分别围绕一个会明显影响结果的主维度形成差异，例如场景、动作、景别或构图；允许必要联动，不能只换同义词或语序。链接标题点明实际差异，不把入口说成已核验候选。
3. 你点击浏览：先选喜欢的图；搜索结果可能因登录、地区或个人推荐不同而变化，也不保证全部符合查询。
4. 反馈给AI：发图或说“保留什么、改什么”。AI只改相关查询。
5. 需要下一步时再提出：比较、裁图、写提示词或融图。不能自动把搜索结果当成定稿或已授权资产。

## 换其他AI时，复制这段

> 请把我的参考需求转成预填英文关键词的Pinterest搜索链接，默认给4–6个，数量以我的要求为准。搜索关键词统一英文，中文需求先转成英文，中文只用于链接标题和说明。保留已确认的共同硬要求，每组围绕一个会明显影响画面结果的主维度形成差异，例如场景、动作、景别或构图；允许必要联动，不能只换同义词、近义表达或语序来充当不同方向。链接标题要点明实际差异。不要实际搜索、打开网页、下载或替我挑图；明确链接只是搜索入口。我自己浏览选图，再把候选发回来。不要自动进入裁图、融图或生成步骤。

## 成功标准

- 链接含完整英文关键词，点击后无需重新输入；不能夹带中文查询词。
- 换词不丢掉主体与硬要求；不同入口在画面层面有可辨认的差异，不用同义词制造假差异；不擅自加明星或旧项目设定。
- “入口已生成”“图片已看过”“适合制作”是三个不同状态，不混为一谈。
- URL格式检查不等于Pinterest结果已验证；本流程也不保证图片授权或融图效果。

理解需求并生成查询仍消耗正常模型用量。你自行浏览筛选不需要AI持续参与。
