# Pinterest搜索入口助手

把需求转成预填关键词的可点击入口；用户自行浏览和挑图，AI只在用户带回图片并请求判断后分析。不启动真正的网络研究或浏览器操作。

## 执行

1. 沿用当前已确认的主体、风格、用途、必须保留和排除项。不要反复问已知信息；人物、服装、场景、画风均按本次需求处理，不套用旧项目的人物或审美。
2. 把需求拆成简短英文搜索词组，而不是生成模型的长提示词。Pinterest搜索框中的关键词统一用英文：中文需求先准确转成英文，不生成中文或中英混合查询；中文仅用于链接标题和说明。默认给4–6个有区别的查询，用户指定数量时遵从。各组保留共同硬要求，并分别围绕一个会明显改变可见结果的主检索维度形成差异，例如场景、动作、景别、构图、服装特征或画风，并以本次需求为准；允许该主维度带来必要联动，不得只替换同义词、近义表达或语序来充当不同方向。输出前做语义去重：若两组去掉这些表面差异后仍在描述同一画面，就合并或重写；无法在保留硬要求时形成真实差异，应如实说明而不是凑数。不要擅自用明星姓名替代用户的描述。
3. 构造 `https://www.pinterest.com/search/pins/?q=` 加查询词的UTF-8百分号编码。只编码查询值一次，空格用`%20`；中文、`&`、`#`、`+`等也要正确编码，不能变成额外参数或片段。不添加模型参数、未经验证的筛选开关或追踪参数。
4. 用中文短标签输出Markdown链接，并在标签中点明各组实际变化的检索维度。简短说明“预填关键词的搜索入口，结果未逐图核验”。不要输出候选名单、缩略图或假装已选好图片。
5. 用户说“不对/换一批”时，只修正有依据的关键词维度，保留其余要求。若不知道偏差，可问一个简短问题；不要把“这批不喜欢”解释为永久排除某类人或某国画风。

## 范围与停止点

- 本Skill只交付搜索入口，不调用网页搜索、图片搜索、浏览器、下载或图像生成工具，也不安装扩展或操作窗口。复杂编码可用本地计算，不需要联网验证每个入口。
- “我直接筛选”表示由用户挑选，不自动构成打开页面或操作浏览器的授权。
- 不宣称“已经搜过”“检查了若干张”“这些都符合要求”。搜索入口不是实际候选；有关键词不代表平台保证命中、排除或固定排序。
- 用户自己浏览选图；本阶段不上传其图片、不保存到外部画板、不自动做后续裁图或融合。
- 用户明确要求实际搜图、核验或操作网页时，按新的请求及可用能力处理并说明已切换任务；不能以本Skill为由拒绝，也不能在只要链接时擅自切换。
- 用户返回候选并要求比较时，分析该次提供的图片和既有要求。选中不等于授权上传、生成或商业复用；MJ参数、裁图、融图另按用户请求处理。
- 读取Skill和生成查询仍有正常模型用量，不作零token承诺。
